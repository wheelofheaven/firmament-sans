# README artwork and screenshots

The brandmark uses Firmament Sans Italic’s `f` with a rust-coloured dot.
The wordmark sets `Firmament.` in Firmament Sans Regular, with the same accent on the full stop.
Both are self-contained SVG paths shaped from the actual 0.1 release fonts; no installed font or remote request is needed.
The palette matches the showcase: paper `#f1f0e9`, forest `#26372f`, and rust `#a74732`.

The canonical renderer is [`scripts/render-brand.py`](https://github.com/wheelofheaven/firmament.wheelofheaven.world/blob/main/scripts/render-brand.py) in the showcase repository.
It uses FontTools and HarfBuzz to preserve the typeface’s outlines and spacing.
Keep copies in the font and showcase repositories aligned when updating the identity.
